# Weather-Web

Weather Website
A simple and responsive weather website that allows users to check current weather conditions and forecasts for different locations.

Features
View current temperature and weather conditions
Search for weather by city or location
Display highest and lowest temperature and chance of rain

Responsive design for desktop, tablet, and mobile devices
Fast and easy-to-use interface

Technologies Used
HTML
CSS
JavaScript
Weather API
Responsive Web Design

🚀 Getting Started
1. Clone the repository
git clone https://github.com/alejandro-ariza1/Weather-Web.git

2. Navigate to the project folder
cd weather-website

3. Open the website
Open index.html in your browser
